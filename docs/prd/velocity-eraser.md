# 속도 반응형 동적 지우개 (Velocity-Based Dynamic Eraser) 구현 계획서

> hi-write(`apps/hi-write/docs/velocity-eraser-plan.md`) 초안을 dk-ink 코드에 맞춰 고쳐 옮겼다.
> 지우개 판정이 dk-ink `editor.ts`의 `eraseTo`에 있으므로 구현은 dk-ink에서 한다.

## 1. 배경

### 1.1 수학 풀이의 두 가지 지우기

1. **정밀 수정**: 지수($x^2$), 첨자($a_n$), 부호, 소수점처럼 좁은 영역의 글자 하나만 지운다.
2. **광역 소거**: 풀이 방향이 틀렸거나 공간이 필요해 여러 줄을 한꺼번에 지운다.

### 1.2 고정 크기 지우개의 한계

- 작게 두면 넓게 지울 때 오래 걸리고 손목이 피곤하다. 크게 두면 지수·부호를 고치다 주변까지 지운다.
- 지우개 두께 슬라이더를 매번 바꾸는 건 풀이 흐름을 끊는다.

### 1.3 해결책

펜을 **천천히 움직이면 작은 원**으로 정밀하게 지우고, **빠르게 문지르면 원이 커져** 넓게 지운다.
별도 UI 조작 없이 손동작만으로 두 모드를 오간다.

**크기는 천천히 바뀌어야 한다.** 빠르게 움직이기 시작해도 바로 커지지 않고, 느려져도 바로
작아지지 않는다.

- 작은 부분을 지울 때 손이 잠깐 빨라져도 원이 튀듯 커져 주변을 지우지 않는다.
- 크게 지운 뒤 마무리로 속도를 늦췄을 때 원이 갑자기 작아져 남은 부분을 못 지우는 일이 없다.
- 왕복으로 문지를 때 방향이 바뀌는 순간(속도 ≈ 0)에도 원이 줄지 않는다.

## 2. 특허 회피 설계 제약 (초안 유지)

- 포인터 이동 속도를 브러시·지우개 반경에 연속적으로 매핑하는 것은 널리 쓰인 공지 기술이다
  (예: MyPaint의 `speed → radius`).
- **쓰지 않는 것**
  - 손바닥·다중 터치 면적과 속도를 결합한 소거 영역 (예: `EP3783474B1`).
  - "N회 왕복하면 전체 삭제" 같은 이산적 모드 전환, 임계치에서 크기가 계단식으로 뛰는 상태 머신
    (예: `US20160098186A1`).
- **쓰는 것**: 단일 포인터의 연속 속도에 **시간 기반 EMA + 선형 보간 + 상하한 제한**만 적용하는
  연속 함수. 홀드 타이머나 상태 머신을 두지 않는다.

> 법적 판단이 아니라 설계 제약이다.

## 3. 알고리즘

### 3.1 순간 속도

coalesced 점마다(`eraseTo`가 받는 점마다) 직전 점과의 거리·시간으로 순간 속도를 구한다. 좌표는
CSS px, 시각은 점이 들고 온 `timeStamp`(ms)다 — `timedPoint`가 이미 둘 다 채운다.

$$v_{inst} = \frac{\sqrt{\Delta x^2 + \Delta y^2}}{\max(\Delta t,\ 1)}\quad(\text{px/ms})$$

### 3.2 시간 기반 비대칭 EMA

계수를 **이벤트마다 고정값**으로 두면 줄어드는 속도가 이벤트 빈도에 따라 달라진다. dk-ink는
coalesced 이벤트를 풀어 점마다 처리하므로 240Hz 기기는 60Hz 기기보다 4배 빨리 반응해 버린다.
그래서 계수를 경과 시간으로 정한다.

$$\alpha = 1 - e^{-\Delta t / \tau},\qquad v_{smooth} \leftarrow v_{smooth} + \alpha\,(v_{inst} - v_{smooth})$$

$$\tau = \begin{cases} \tau_{up} & v_{inst} > v_{smooth} \\ \tau_{down} & \text{그 외} \end{cases}$$

- $\tau_{up}$: 커지는 데 걸리는 시간. 빠르게 문지르기 시작하면 약 $\tau_{up}$ 뒤에 목표의 63%,
  $3\tau_{up}$ 뒤에 95%에 닿는다. **바로 커지지 않게** 하는 값이다.
- $\tau_{down}$: 작아지는 데 걸리는 시간. 왕복 변곡점과 마무리 지우기에서 크기를 유지한다.
  **바로 작아지지 않게** 하는 값이다. 너무 길면 빠르게 옮긴 직후 정밀하게 지울 때 옆 글씨가
  지워지므로 너무 길게 잡지 않는다.
- 펜을 멈춘 채 대고 있으면 이벤트가 오지 않는다. 다음 이동 때 긴 $\Delta t$가 그대로 반영돼 원이
  줄어드므로 **rAF 감쇠 루프는 두지 않는다.**

### 3.3 지름 매핑

dk-ink는 지우개 크기를 지름(`eraserWidth`)으로 다루므로 지름으로 적는다.

$$u = \mathrm{clamp}\!\left(\frac{v_{smooth} - v_{min}}{v_{max} - v_{min}},\ 0,\ 1\right),\qquad W = W_{min} + (W_{max} - W_{min})\,u$$

### 3.4 초기 파라미터 (P580에서 튜닝)

| 파라미터       | 기호          | 초기값      | 설명                                           |
| -------------- | ------------- | ----------- | ---------------------------------------------- |
| 최소 지름      | $W_{min}$     | `20px`      | 지수·부호 수정용. 펜 뒤집기 작은 지우개와 같음 |
| 최대 지름      | $W_{max}$     | `180px`     | 여러 줄을 한 번에 지울 때                      |
| 반응 시작 속도 | $v_{min}$     | `0.4 px/ms` | 이하에서는 항상 $W_{min}$ (손떨림 데드존)      |
| 최대 도달 속도 | $v_{max}$     | `2.5 px/ms` | 이상에서는 항상 $W_{max}$                      |
| 커지는 시간    | $\tau_{up}$   | `150ms`     | 바로 커지지 않게                               |
| 작아지는 시간  | $\tau_{down}$ | `400ms`     | 바로 작아지지 않게                             |

처음에는 모두 모듈 상수로 둔다. 손에 맞는 값이 정해진 뒤 옵션 공개 여부를 정한다.

## 4. 고속 이동 시 건너뜀(터널링)

**이미 해결돼 있다.** `eraseStrokes(strokes, from, to, diameter)`가 직전 점→현재 점 선분을
지름만큼 두꺼운 캡슐로 판정한다. 동적 지우개에서는 두 점의 지름 중 **큰 값**을 넘기면 된다.
반경이 변하는 캡슐(tapered)은 만들지 않는다.

## 5. 기존 기능과의 관계

- **지우개 두께 설정**: 동적 지우개가 켜져 있으면 크기는 $W_{min}$~$W_{max}$로 정해지므로
  `eraserWidth` 슬라이더는 의미가 없다. 켜져 있는 동안 playground·hi-write 설정 패널에서 슬라이더를
  숨기거나 비활성화한다. 꺼져 있으면 지금처럼 `eraserWidth` 고정 크기로 동작한다.
- **펜 뒤집기 작은 지우개** (`pen-flip.ts`, `FLIPPED_ERASER_WIDTH = 20`): 정밀 수정용이므로
  뒤집은 동안에는 동적 지우개를 끄고 고정 20px로 지운다. 지금 `eraserWidth`를 저장·복원하는 것처럼
  동적 설정도 저장·복원한다.
- **지우개 커서**: `drawEraserCursor`가 `style.eraserWidth` 대신 **지금 계산된 지름**으로 그린다.
- **되돌리기**: 영향 없음. 지우개 한 제스처가 한 번의 이력이라는 규칙은 그대로다.
- **성능**: 원이 커지면 한 번에 닿는 획이 늘어 다 쓴 획 층을 다시 그리는 일이 잦아질 수 있다.
  지우개는 이미 rAF로 모아 그리므로 우선 그대로 두고, 느리면 그때 획 경계 상자 캐시를 검토한다.

## 6. 구현 단계

### Step 1. 지름 계산 순수 모듈 (`src/dynamic-eraser.ts`)

- DOM·Canvas에 의존하지 않는다.
- `next(point: InkPoint): number` — 점을 받아 지금 지름을 돌려준다. 첫 점은 $W_{min}$.
- `reset()` — `pointerdown`/`pointerup`에서 $v_{smooth} = 0$, 지름 $W_{min}$으로.

### Step 2. 단위 테스트 (happy path 먼저)

1. 느리게 움직이면 지름이 $W_{min}$에 머문다.
2. 빠르게 계속 움직이면 지름이 **한 번에 뛰지 않고** 점점 커져 $W_{max}$ 이하로 수렴한다
   (예: 첫 $\tau_{up}$ 안에서는 $W_{max}$의 절반에 못 미친다).
3. 빠른 왕복 중 방향 전환(속도 ≈ 0) 점에서 지름이 크게 줄지 않는다.
4. 느려지면 **천천히** $W_{min}$으로 돌아간다.
5. 같은 손동작을 60Hz·240Hz 간격으로 넣어도 같은 시간 뒤의 지름이 거의 같다 (시간 기반 EMA 확인).
6. 오래 멈췄다 다시 움직이면 지름이 $W_{min}$ 근처에서 다시 시작한다.

### Step 3. 에디터 연동

- `InkStyle`에 `dynamicEraser: boolean` 추가 (기본 `false`).
- `eraseTo`에서 켜져 있으면 점마다 지름을 계산해 `eraseStrokes`에 넘기고 커서도 그 지름으로 그린다.
- 에디터 테스트: 빠르게 문지르면 고정 $W_{min}$으로는 닿지 않는 획이 지워진다.

### Step 4. 실험용 토글

- playground·hi-write 설정 패널에 "동적 지우개 켜기/끄기" 토글을 넣고 설정을 저장한다.
- 켜져 있으면 지우개 두께 슬라이더를 숨긴다.
- P580에서 끄고 켜며 비교하고 3.4 파라미터를 튜닝한다.
