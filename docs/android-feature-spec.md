# dk-ink 기능 명세 (Android 네이티브 구현용)

이 문서는 dk-ink 플레이그라운드(`playground/index.html`)가 **무엇을 하는지**를 적은 것이다. 어떻게 구현했는지(층 나누기, 캐시, 프레임 예약 같은 성능 기법)는 적지 않았다. 이 문서만 보고 Android 앱을 만들면 사용자가 보고 겪는 동작이 웹과 같아야 한다.

기준 버전: v0.1.120 (2026-11-09)

## 0. 단위와 용어

- **px**: 웹의 CSS 픽셀이다. Android에서는 **dp**로 옮긴다. 이 문서의 모든 길이·굵기·거리는 dp로 읽는다.
- **ms**: 밀리초.
- **필압**: 0~1 사이 값. Android `MotionEvent.getPressure()`에 해당한다. 필압을 알려 주지 않는 입력은 **0.5**로 친다.
- **펜**: 스타일러스(S펜 등). **손가락**: 터치. **마우스**: 마우스 포인터.
- **호버**: 펜이 화면에 닿지 않고 가까이 떠 있는 상태.
- **누름 / 뗌**: 포인터가 화면에 닿음(`ACTION_DOWN`) / 떨어짐(`ACTION_UP`). 시스템이 입력을 취소하면(`ACTION_CANCEL`) **뗌과 똑같이** 처리한다. 진행 중이던 획은 버리지 않고 남는다.
- **캔버스**: 필기하는 영역. 좌표의 원점은 캔버스 왼쪽 위다.

## 1. 화면 구성

위에서 아래로:

1. **머리글**: 왼쪽에 `dk-ink v{버전}`을 표시한다 (버전은 작은 회색 글씨 `#68758a`, 12). 오른쪽에 `획 N개`를 표시한다. N은 지금 남아 있는 획 수이고, 획이 바뀔 때마다(획을 마침, 지움, 되돌리기, 다시 하기, 전체 지우기) 갱신한다. 지우개로 획 가운데를 끊으면 조각이 두 개가 되므로 N이 늘어날 수 있다.
2. **무대(캔버스 영역)**: 남은 공간을 모두 채운다. 그 위에 떠다니는 **도구 모음**, **설정 패널**, **따라다니는 펜 아이콘**이 겹친다.

### 1.1 무대의 모습

- 배경색 `#f4f6f9`.
- 24 간격의 모눈선. 선 색 `#e2e6eb`, 굵기 1. 가로·세로 모두.
- 획은 모눈 **위에** 그려진다 (획이 모눈선을 가린다).

### 1.2 겹치는 순서 (아래 → 위)

모눈 배경 → 획 → 따라다니는 펜 아이콘 → 도구 모음 → 설정 패널

## 2. 데이터 모델

획은 저장·전송할 수 있는 순수 데이터다.

```
Stroke {
  points: InkPoint[]   // 누른 순간부터 뗀 순간까지의 점
  style:  StrokeStyle  // 이 획을 그릴 때 쓴 속성. 획마다 따로 들고 있다
}
InkPoint {
  x, y: number         // 캔버스 기준 좌표(dp)
  t: number            // 그 점이 실제로 샘플된 시각(ms). 이벤트 처리 시각이 아니다
  pressure?: number    // 0~1. 필압을 알려 주지 않는 입력이면 없음
}
StrokeStyle {
  color: string        // 예: "#3d7bd9"
  strokeWidth: number  // 굵기. 필압 모드에서는 최대 굵기
  widthMode: "pressure" | "constant"
  opacity: number      // 0~1
}
```

- 획의 `style`은 **펜을 댄 순간의 설정을 복사**한 값이다. 나중에 색·굵기·필기 방식을 바꿔도 이미 그린 획은 바뀌지 않는다.
- 캔버스 크기가 바뀌어도 획 좌표는 그대로다. 비율에 맞춰 늘리거나 줄이지 않는다.

## 3. 펜으로 쓰기

### 3.1 입력 받기

- 펜 끝이 화면에 닿으면(누름) **바로** 획을 시작한다. 앱에는 필압 문턱값이 없다. 얼마나 눌러야 닿은 것으로 치는지는 기기와 OS가 정한다.
- 누른 점, 움직인 점, 뗀 점을 모두 획에 넣는다.
- 기기가 이벤트 여러 개를 하나로 묶어 보내면 **묶인 점까지 모두** 넣는다 (Android: `getHistoricalX/Y/Pressure/EventTime`). 이렇게 해야 빠르게 그어도 궤적이 각지지 않는다.
- **예측 점은 쓰지 않는다.** 예측 점을 쓰면 방향을 꺾을 때 선이 펜이 가지 않은 곳까지 잠깐 삐져나갔다 돌아온다.
- 손가락을 캔버스 밖으로 끌고 나가도 뗄 때까지 같은 획이 이어진다. 이때 좌표가 캔버스 밖(음수 등)이어도 그대로 저장한다.
- **한 번에 하나의 포인터만** 다룬다. 획을 쓰는 중에 들어온 다른 포인터(두 번째 손가락 등)는 무시한다.
- 쓰는 중에 도구나 설정을 바꿔도 진행 중인 획에는 영향이 없다. 다음 획부터 적용된다.

### 3.2 필압 → 굵기 (필기 방식 "필압적용")

점마다 목표 굵기를 이렇게 정한다. `W`는 설정한 펜 두께(최대 굵기)이고, `p`는 필압이다. 필압이 없으면 0.5로 친다.

```
p' = clamp(p, 0, 1)
r  = min(1, p' / 0.6)
굵기 = 0.3 + (W - 0.3) × r
```

- 필압 0이면 가장 가는 굵기인 **0.3**이다.
- 필압 **0.6 이상**이면 최대 굵기 `W`다.
- 0과 0.6 사이에서는 필압에 정비례한다.

예시 (W = 3):

| 필압                 | 굵기 |
| -------------------- | ---- |
| 0                    | 0.3  |
| 0.3                  | 1.65 |
| 0.5 (필압 없는 입력) | 2.55 |
| 0.6 이상             | 3    |

**굵기는 필압을 바로 따라가지 않고 부드럽게 바뀐다.** 점을 차례로 보면서:

1. 직전에 쓴 점과의 거리가 **0.35 미만**인 점은 건너뛴다.
2. 첫 점의 반지름은 `목표굵기 / 2`다.
3. 그다음 점의 반지름은 `직전 반지름 × 0.65 + 목표반지름 × 0.35`다.

그래서 갑자기 세게 눌러도 몇 점이 지나야 최대 굵기에 닿는다.

**모양:**

- 점마다 반지름이 다른 하나의 채워진 도형으로 그린다. 양쪽 외곽선은 각 점에서 진행 방향에 수직으로 반지름만큼 떨어진 점들을 잇는다.
- 외곽선은 각 점을 제어점으로 삼아 이웃 점과의 중점까지 2차 곡선으로 부드럽게 잇는다. 마지막 점까지는 직선으로 닿는다.
- 양 끝은 반원으로 둥글게 닫는다.
- 건너뛰고 남은 점이 하나뿐이면 그 자리에 반지름만큼의 채워진 원(점)을 그린다.

### 3.3 고정 두께 (필기 방식 "고정두께")

- 필압과 관계없이 굵기가 `W`로 일정한 선이다. 끝과 꺾이는 곳은 둥글다 (round cap, round join).
- 점을 제어점으로 삼아 이웃 점과의 중점까지 2차 곡선으로 잇는다. 시작점과 끝점은 입력 그대로다.
- **90°보다 크게 꺾이는 점**은 곡선으로 깎지 않는다. 그 점을 정확히 지나게 해서 모서리를 살린다. 판정 방법: (앞 점→이 점)과 (이 점→다음 점)의 내적이 0보다 작으면 90°보다 크게 꺾인 것이다.
- 제자리에서 찍은 획(점이 하나이거나 모든 점이 같은 자리)은 지름 `W`의 둥근 점으로 그린다.

### 3.4 색과 투명도

- 모든 획의 불투명도는 **0.8**이다 (설정 화면에서 바꿀 수 없다). 쓰는 동안에도 처음부터 0.8 반투명으로 그린다.
- 획은 반투명이어야 한다. **불투명으로 바꾸면 안 된다.** 이 앱은 문항 위에 풀이를 쓰는 용도라서, 획 아래의 문항 글자가 비쳐 보여야 한다.
- 서로 다른 획이 겹친 곳은 더 진해진다. 한 획이 자기 자신과 겹친 곳은 진해지지 않는다. 한 획은 한 번에 칠한 도형이기 때문이다.

## 4. 길게 멈춰 직선·원 만들기 (펜 도구)

곧게 긋다가 끝에서 펜을 대고 멈추면, 그은 선이 시작점과 끝점을 잇는 반듯한 직선으로 바뀐다. 원을 그리다가 시작점 근처에서 멈추면 정원으로 바뀐다.

**켜고 끄기:** 설정의 "길게 눌러 직선"과 "길게 눌러 원"으로 따로 켜고 끈다. 둘 다 기본은 켬.

**대기 시간:** 설정의 "도형 대기 시간"을 직선과 원이 함께 쓴다. 기본 0.7초. 0.5~1.5초 범위에서 0.1초 단위로 고른다.

### 4.1 멈춤 판정

- 직선과 원 설정이 모두 꺼져 있으면 대기 시간을 재지 않는다.
- 획에 점이 들어올 때마다 "머문 자리"와 비교한다. 아직 머문 자리가 없거나 새 점이 머문 자리에서 **8보다 멀면** 그 점을 새 머문 자리로 삼고 대기 시간을 처음부터 다시 잰다.
- 8 이내에서 흔들리는 것은 멈춘 것으로 본다. 대기 시간이 계속 흐른다.
- 펜이 완전히 멈춰 이벤트가 오지 않아도 대기 시간은 흐른다.
- 시간이 다 되면 바꿀 모양을 정한다. 원 설정이 켜져 있으면 원 조건(4.4)을 먼저 확인한다. 원이 아니고 직선 설정이 켜져 있으면 직선 조건(4.2)을 확인한다.
- 원도 직선도 아니면 아무 일도 일어나지 않는다. 그 뒤 펜이 다시 8 넘게 움직이면 대기 시간을 처음부터 다시 잰다.

### 4.2 직선으로 바꾸는 조건

시간이 다 됐을 때 아래를 **모두** 만족해야 바꾼다.

- 첫 점과 마지막 점 사이의 거리가 **16 이상**이다. 획을 시작하며 머뭇거린 경우를 거른다.
- 획의 **모든 점**이 첫 점–마지막 점 선분에서 `max(6, 길이 × 0.08)` 이내에 있다. 길게 그은 선의 손떨림은 받아 주고, ㄱ·L처럼 꺾인 획이나 갔다 되돌아온 획은 거른다.

### 4.3 직선으로 바뀐 뒤

- 획의 점이 [첫 점, 지금 마지막 점] 두 개로 줄어든다.
- 그 획의 필기 방식이 **고정두께**로 바뀐다. 색과 투명도는 그대로다.
- 굵기는 쓰던 필기 방식에 따라 다르다. **필압적용**으로 쓰던 획은 `W × 0.7`이 되고(W = 3이면 2.1), **고정두께**로 쓰던 획은 `W` 그대로다. 필압 글씨는 최대 굵기보다 가늘게 써지므로, 보정한 도형만 굵어 보이지 않게 줄인다. 줄인 값이 그 획의 `strokeWidth`로 저장된다.
- **시작점 표시**: 첫 점 자리에 반지름 `max(6, 바뀐 뒤 굵기)`인 채워진 원을 그 획의 색으로 **불투명하게**(투명도 1) 그린다.
- 펜을 떼기 전까지 끝점이 펜을 따라 움직인다. 시작점은 고정이다. 이 동안 대기 시간은 더 재지 않는다.
- 펜을 떼면 뗀 자리가 끝점이 되고 시작점 표시는 사라진다. 저장되는 획은 점 두 개짜리 고정두께 직선이다.

### 4.4 원으로 바꾸는 조건

앞뒤에 짧게 삐져나온 꼬리가 있어도 원을 찾을 수 있도록, 획의 양 끝을 조금씩 잘라 낸 후보를 차례로 검사한다.

1. 입력 점이 **12개 미만**이면 원이 아니다.
2. 획을 길이 기준으로 96등분해 같은 간격의 점 **97개**로 다시 뽑는다. 첫 점과 마지막 점은 입력 그대로다.
3. 잘라 낼 개수 `trim`을 0부터 24까지(전체의 25%) 늘려 간다. `trim`마다 앞에서 `start`개(0~`trim`), 뒤에서 `trim - start`개를 잘라 후보를 만든다.
4. 후보마다 아래 두 검사를 모두 통과해야 한다. 통과한 후보 중 `점수 = error + (trim / 97) × 0.01`이 가장 낮은 후보의 중심과 반지름을 쓴다. 비슷하게 맞으면 덜 잘라 낸 후보가 뽑힌다.
5. `trim`이 0인 후보가 통과하면 더 잘라 보지 않는다.

```
맞춤 검사
  중심 = 후보 점들을 감싸는 사각형의 가운데
  r = (사각형 폭 + 사각형 높이) / 4
  r < 12이면 실패
  첫 점과 마지막 점 사이 거리 > r × 0.9이면 실패      // 시작점 근처까지 돌아와야 한다
  점마다 d = (중심까지 거리) - r
    |d| > r × 0.35이면 실패
  이웃한 두 점이 중심을 기준으로 도는 각도를 부호를 붙여 더한다
    |각도의 합| < 297° (1.65π)이면 실패              // 덜 돌았다
    (각도 절댓값의 합) > 450° (2.5π)이면 실패        // 두 바퀴 돌았거나 되돌아갔다
  error = (d / r)²의 평균

고른 휘어짐 검사                                     // 사각형·다각형을 거른다
  앞뒤로 4칸씩 점이 있는 i마다
    turn = (p[i] - p[i-4])와 (p[i+4] - p[i]) 사이 각도의 절댓값
  mean = turn의 평균
  turn < mean × 0.3인 점이 전체의 25%를 넘으면 실패
```

- 보정되는 예: 0.875바퀴쯤 그리고 멈춘 원, 가로 100·세로 56으로 찌그러진 원, 앞뒤에 짧은 꼬리가 달린 원.
- 보정되지 않는 예: 반 바퀴나 3/4 바퀴만 그린 호, 두 바퀴 그린 원, 사각형·다각형, 원에 비해 너무 긴 꼬리가 달린 획.

### 4.5 원으로 바뀐 뒤

- 획의 점이 정원을 따라 놓인 점 목록으로 바뀐다. 점 개수는 `N = clamp(ceil(2πr / 4), 64, 512)`이다. 각도 0(중심의 오른쪽)에서 시작해 `360° / N` 간격으로 놓고, 끝에 첫 점을 한 번 더 넣어 닫는다. 그래서 점은 `N + 1`개다. 모든 점의 시각과 필압은 지금 펜 점의 값을 복사한다.
- 필기 방식과 굵기는 4.3과 똑같이 바뀐다. 그리는 방법은 3.3을 따른다.
- **중심 표시**: 원의 중심에 4.3의 시작점 표시와 같은 모양을 그린다.
- 펜을 떼기 전까지 중심은 고정되고, 펜과 중심 사이의 거리에 따라 크기가 바뀐다. 이 동안 대기 시간은 더 재지 않는다.
  - `새 반지름 = max(1, 펜–중심 거리 + offset)`
  - `offset = 인식한 반지름 - 보정 순간의 펜–중심 거리`. 보정 순간에 펜이 원둘레에서 조금 벗어나 있어도 첫 움직임에서 크기가 튀지 않게 하는 값이다.
- 펜을 떼면 뗀 자리로 반지름을 한 번 더 계산해 확정하고 중심 표시는 사라진다. 저장되는 획은 일반 고정두께 획이므로 되돌리기와 지우개도 다른 획과 똑같이 동작한다.

## 5. 직선 도구

도구 모음의 직선 버튼으로 켠다.

- 누른 자리가 시작점이다. 누르자마자 **시작점 표시**(4.3과 같은 모양)가 보인다. 움직이기 전까지는 선이 없다.
- 움직이면 시작점과 지금 펜 위치를 잇는 직선이 보인다. 펜을 떼면 뗀 자리에서 끝난다.
- 항상 **고정두께**로 그린다. 설정의 필기 방식과 관계없다. 굵기는 설정한 펜 두께이고(4.3의 0.7배를 적용하지 않는다), 색은 설정한 색, 투명도는 0.8이다.
- 움직이지 않고 떼면 시작점 자리에 둥근 점 하나가 남는다.
- 직선 도구는 다시 누를 때까지 켜져 있다. 다시 누르면 펜으로 돌아간다.
- 직선 도구에서는 "길게 멈춰 직선·원"이 동작하지 않는다.

## 6. 지우개

### 6.1 지우는 방식

- 획 단위로 통째로 지우지 않는다. **지우개가 지나간 부분만 잘라 낸다.** 획 가운데를 지나가면 획이 두 조각으로 남는다.
- 지우개 모양은 원이다. 연속한 두 입력 점 사이에서는 **두 점을 잇는 캡슐 모양**(선분 + 양 끝 반원) 전체를 지운다. 그래서 빠르게 움직여도 중간을 건너뛰지 않는다. 캡슐의 지름은 이전 점의 지름과 지금 점의 지름 중 큰 값이다.
- 누른 순간에도 그 자리의 원 하나만큼 지운다.
- 묶여서 들어온 점(historical)도 하나씩 차례로 지운다.

**잘라 내는 규칙:**

- 지우개 판정은 획의 점 사이를 **1.5 이하 간격**으로 촘촘히 나눈 점으로 한다. 점이 지우개 반경 안에 있으면(경계 포함) 지운다.
- 남은 조각에는 **원래 입력 점만** 남긴다. 다만 잘린 경계에는 경계에 가장 가까운 보간 점을 하나씩 넣는다. 보간 점을 전부 남기면 곡선이 각져 보이기 때문이다. 보간 점의 시각과 필압은 양쪽 점에서 선형으로 보간한다 (필압이 한쪽만 있으면 없는 쪽을 0.5로 친다).
- 점이 1개 이하로 남은 조각은 버린다.
- 점 하나짜리 획(찍은 점)은 지우개 반경 안에 들면 통째로 사라진다.
- 잘린 조각은 원래 획의 `style`을 그대로 물려받는다. 조각은 원래 획이 있던 자리(그리는 순서)에 놓인다.

### 6.2 지우개 크기

**고정 크기**: 설정의 "지우개 두께". 지름 기본 50, 범위 8~100, 2 단위. 동적 지우개를 켜면 이 설정 줄은 숨는다.

**동적 지우개** (흔들면 커지는 지우개): 설정의 "동적 지우개". 플레이그라운드 기본은 **켬**. 켜면 고정 크기를 쓰지 않는다. 빠르게 문지를수록 지우개가 커지고, 느리게 움직이면 천천히 작아진다.

점마다 아래처럼 계산한다. 시간 단위는 ms, 거리 단위는 dp다.

```
상수
  최소 지름 20,   최대 지름 180
  최소 속도 0.4,  최대 속도 2.5   (dp/ms)
  곡선 지수 1.5
  커질 때 시간상수 150,  작아질 때 시간상수 1400
  안정화 시간상수 800

상태 (누를 때마다 0으로 초기화): 이전 점, smoothed = 0, displayed = 0

새 점마다:
  이전 점이 있으면:
    dt = max(t - 이전 t, 1)
    v  = 두 점 사이 거리 / dt                 // 순간 속도
    tau = (v > smoothed) ? 150 : 1400
    smoothed += (1 - e^(-dt / tau)) × (v - smoothed)
    if smoothed > displayed: displayed = smoothed
    else: displayed += (1 - e^(-dt / 800)) × (smoothed - displayed)
  이전 점 = 지금 점
  ratio = clamp((displayed - 0.4) / (2.5 - 0.4), 0, 1)
  지름 = 20 + (180 - 20) × ratio^1.5
```

- 누른 첫 점의 지름은 항상 20이다.
- 커질 때는 빠르게(150ms) 따라가고, 작아질 때는 두 단계로 걸러서 처음에는 거의 그대로 있다가 천천히 줄어든다.
- 계산에 경과 시간을 쓰므로 이벤트 빈도(60Hz, 240Hz)와 관계없이 같은 속도면 같은 크기가 된다.
- 펜을 대고 가만히 있을 때 줄어들게 하는 타이머는 없다. 다음에 움직일 때 그동안의 긴 간격이 반영되어 한 번에 줄어든다.

### 6.3 지우개 커서

- 지우개를 누르고 있는 동안에만 펜 위치에 원을 그린다. 원의 지름은 그 순간의 지우개 지름이다.
- 채우기 `rgba(15, 118, 110, 0.12)`, 테두리 `#0f766e`, 테두리 굵기 1, 점선(4 그리고 3 간격).
- 떼면 바로 사라진다. 호버 중에는 그리지 않는다.

## 7. 되돌리기 / 다시 하기 / 전체 지우기

- 되돌리기 단위:
  - 펜 획 하나(길게 멈춰 직선이나 원으로 바뀐 획 포함), 또는 직선 도구로 그은 직선 하나 = 1단계.
  - 지우개를 눌렀다 뗄 때까지 = 1단계. 단 **실제로 무언가 지워진 경우에만** 쌓는다. 아무것도 못 지운 지우개 동작은 이력을 건드리지 않는다 (다시 하기 목록도 그대로 남는다).
  - 전체 지우기 = 1단계.
- 최대 **50단계**까지 기억한다. 넘으면 가장 오래된 것부터 버린다.
- 새 동작(획, 실제 지우기, 전체 지우기)을 하면 다시 하기 목록을 비운다.
- 되돌리기·다시 하기를 할 수 없으면 해당 버튼이 비활성화된다 (불투명도 0.45, 눌러도 반응 없음).
- **전체 지우기**는 확인 창 없이 바로 모든 획을 지운다. 되돌리기로 살릴 수 있다. 획이 하나도 없으면 아무 일도 하지 않는다 (이력에도 쌓지 않는다).
- 되돌리기·다시 하기·전체 지우기를 하는 순간 진행 중인 획이나 지우기가 있으면 그 동작을 끝낸 것으로 친다.

### 8.3 도구 상태와 버튼 표시

도구는 셋 중 하나다: **펜**, **지우개**, **직선**. 앱을 켜면 펜이다 (도구는 저장하지 않는다).

| 지금 도구 | 펜 버튼   | 지우개 버튼 | 직선 버튼 |
| --------- | --------- | ----------- | --------- |
| 펜        | 눌린 상태 | 보통        | 보통      |
| 지우개    | 보통      | 눌린 상태   | 보통      |
| 직선      | 보통      | 보통        | 눌린 상태 |

따라다니는 펜을 뒤집어 작은 지우개로 쓰는 중(10.3)에도 지우개 버튼이 눌린 상태로 보인다.

- **펜 버튼**: 펜을 고른다. 이미 펜이면 아무 변화가 없다.
- **지우개 버튼**: 지우개를 고른다. 이미 지우개이면 아무 변화가 없다.
- **직선 버튼**: 직선이면 펜으로, 아니면 직선으로 바뀐다.
- 따라다니는 펜이 뒤집힌 상태(10.4)에서 셋 중 어느 버튼을 눌러도, 먼저 뒤집힌 상태를 풀고 지우개 두께를 되돌린 뒤 그 버튼의 동작을 한다.

### 8.4 버튼이 반응하는 시점

- 도구 모음 버튼은 **누르는 순간** 동작한다. 떼는 순간이 아니다.
- 같은 버튼은 한 번 동작한 뒤 **500ms 동안** 다시 동작하지 않는다. 한 번의 입력이 여러 경로(펜 이벤트와 터치 이벤트)로 두 번 들어와 두 번 뒤집히는 것을 막기 위해서다.
- 마우스는 왼쪽 버튼만 받는다.
- 손가락 입력 설정(9)이 꺼져 있어도 도구 모음은 손가락으로 누를 수 있다.

**도구 전환 방식** (설정 "도구 전환"): 펜, 지우개, 직선 버튼에만 적용된다.

- **탭** (기본): 누르면 그 버튼이 동작한다.
- **호버**: 펜이나 마우스가 버튼 영역 **안으로 들어오는 순간** 그 버튼이 동작한다. 닿지 않고 떠 있어도 된다. 영역 안에 머무는 동안은 다시 동작하지 않고, 나갔다 다시 들어오면 또 동작한다. 그래서 직선 버튼은 들어올 때마다 켜짐과 꺼짐이 바뀌고, 펜·지우개 버튼은 그 도구를 다시 고를 뿐이다. 이 방식에서는 펜·마우스로 버튼을 눌러도 전환되지 않는다 (호버로 이미 전환됐기 때문). 손가락에는 호버가 없으므로 손가락으로 누르면 탭처럼 전환된다. 손가락으로 버튼 위를 스치는 것은 전환으로 치지 않는다.

### 8.5 끌어서 옮기기

- 손잡이를 누르고 끌면 도구 모음이 따라온다. 손잡이를 잡은 지점과 도구 모음의 상대 위치는 유지한다.
- 무대 안에 머물도록 위치를 제한한다. 왼쪽·오른쪽·아래는 무대 가장자리에서 8 안쪽까지만 갈 수 있다.
- 위쪽 한계: 웹에서는 무대 위에 있는 개발용 "입력 진단" 패널의 위쪽 + 8까지 올라갈 수 있다. Android에 그 패널이 없다면 무대 위쪽에서 8 안쪽까지로 한다.
- 화면(창) 크기가 바뀌면 지금 위치를 같은 규칙으로 다시 제한한다.
- 옮긴 위치는 저장하지 않는다.

### 8.6 펜이 가까이 있을 때 회색 표시

일부 기기는 펜이 화면 가까이 떠 있는 동안 손가락 터치를 OS에서 막는다. 그래서 그 상태를 알려 준다.

- 펜이 근접(호버 또는 닿음)해 있으면 도구 모음의 **도구 버튼 아이콘 색**을 `#9aa4b2`(회색)로 바꾼다. 도구 모음 배경은 그대로다. 색은 0.12초 동안 바뀐다.
- 펜이 **도구 모음 위**에 있을 때는 회색으로 하지 않는다. 그 펜은 실제로 버튼을 누를 수 있기 때문이다.
- 펜 근접이 끝났다고 보는 때:
  - 마지막 펜 이벤트(호버 이동, 누름, 뗌) 뒤 **700ms** 동안 펜 이벤트가 없을 때.
  - 펜이 호버 범위를 벗어났다는 알림(Android: `ACTION_HOVER_EXIT`)이 오고, **200ms** 동안 펜 이벤트가 다시 오지 않을 때. 200ms 안에 다시 오면 계속 근접으로 본다. 기기에 따라 펜을 뗄 때마다 이 알림이 와서 표시가 깜빡이기 때문이다.
- 회색이어도 펜으로는 버튼이 눌린다.

## 9. 손가락 입력

- 설정 "손가락 입력". 기본은 **끔**.
- 끄면 손가락으로 캔버스에 쓰거나 지울 수 없다. 펜으로 쓰는 동안 손바닥이나 손가락이 닿아 획이 생기는 것을 막기 위해서다.
- 도구 모음과 설정 패널은 이 설정과 관계없이 손가락으로 쓸 수 있다.
- 마우스는 이 설정과 관계없이 캔버스에 쓸 수 있다.

## 10. 따라다니는 펜

펜이 캔버스 위에 떠 있으면 펜 끝 옆에 작은 연필 아이콘이 따라다닌다. 이 아이콘을 탭하면 연필이 뒤집혀 작은 지우개가 된다. 실제 연필 뒤쪽의 지우개로 지우는 느낌을 주려는 기능이다.

**켜고 끄기:** 설정 "따라다니는 펜". 기본 **켬**. 끄면 아이콘이 사라지고, 뒤집혀 있었다면 원래대로(펜) 돌린다.

**펜 입력에만** 반응한다. 손가락과 마우스에는 나타나지 않는다.

### 10.1 아이콘 모양

- 40×40, 흰 배경, 모서리 반지름 9. 아이콘 전체의 불투명도는 **0.3**이라 아래 필기가 비친다.
- 가운데에 연필 그림(SVG ①) 28×28, 색 `#182231`.
- 지우개 도구일 때는 아이콘 전체가 **180° 회전**한다 (0.15초, ease-out).
- **누를 수 있는 곳은 가운데 28×28 그림 영역뿐이다.** 그 바깥 여백을 누르면 아래 캔버스에 쓴다.
- 도구 모음보다 아래, 획보다 위에 그린다.

### 10.2 위치와 따라다니기

- **기본 자리**: 아이콘의 **왼쪽 아래 모서리**가 펜 끝에 오는 자리. 즉 아이콘 중심 = (펜 x + 20, 펜 y − 20).
- **나타나기**: 숨어 있다가 펜이 캔버스 위에 떠 있으면 기본 자리에 바로 놓고, **1000ms** 동안 투명에서 0.3까지 서서히 나타난다 (ease-out).
- **따라가기**: 보이는 중에 펜이 움직이면:
  - 펜이 아이콘 중심에서 **24 이내**에 있으면 누르려는 것으로 보고 움직이지 않는다.
  - 새 기본 자리가 지금 아이콘 자리에서 **8 이하**로 떨어져 있으면 손떨림으로 보고 무시한다.
  - 그 밖의 경우 **500ms 뒤**에 옮기도록 예약한다. 예약은 하나만 건다. 이미 예약이 있으면 새로 걸지 않는다. 실행 시점에는 **가장 최근** 펜 위치의 기본 자리로 간다. 그 시점에 펜이 아이콘 24 이내에 있으면 옮기지 않는다.
  - 옮길 때는 **0.18초** 동안 미끄러지듯 움직인다. 처음엔 빠르고 끝으로 갈수록 느려진다 (cubic-bezier(0.25, 1, 0.5, 1)).
  - 500ms를 기다리는 이유: 그사이에 펜을 아이콘으로 가져가 누를 수 있게 하기 위해서다.
- **숨기기**: 다음일 때 아이콘을 숨기고 예약된 이동도 취소한다.
  - 펜이 캔버스에 닿아 쓰는 중일 때 (지우개 도구로 지우는 중은 예외, 10.4).
  - 펜이 캔버스 밖(도구 모음 위 포함)에 떠 있을 때. 아이콘 위는 캔버스 안으로 친다.
  - 펜 근접이 끝났을 때 (8.6과 같은 판정). 단 아이콘이 뒤집혀 있거나, 아이콘을 누르고 있거나, 펜으로 돌아가는 회전이 아직 끝나지 않았으면 숨기지 않는다.
- **획 사이에 깜빡이지 않기**: 펜으로 획을 마친 뒤 **500ms 동안**은 숨은 아이콘을 다시 띄우지 않는다.

### 10.3 펜 아이콘 누르기 (펜 → 작은 지우개)

- 아이콘 그림을 펜으로 누르면 **그 자리에서 바로 필기가 시작된다** (아이콘이 없는 것처럼). 아이콘은 제자리에 머문다.
- 누른 뒤 **300ms 이내**에, 누른 자리에서 **8 이하**로만 움직이고 떼면 **탭**이다.
  - 누르며 캔버스에 찍힌 점은 필기가 아니므로 지운다. 누르기 전보다 획이 정확히 1개 늘었으면 되돌리기를 한 번 한다. (그래서 이 점은 다시 하기 목록에 남는다. 다시 하기를 누르면 그 점이 돌아온다.)
  - 연필이 **뒤집혀**(180° 회전) 작은 지우개가 된다. 도구가 지우개로 바뀌고, 도구 모음의 지우개 버튼이 눌린 상태가 된다.
  - 이때 지우개 지름은 **20**이다. 뒤집기 전의 지우개 두께 설정은 기억해 두었다가 원래대로 돌릴 때 되돌린다.
  - 단, **동적 지우개가 켜져 있으면** 20이 아니라 동적 크기(6.2)로 지운다. 지금 구현이 그렇다.
- 8보다 멀리 움직이거나 300ms보다 오래 누르면 탭이 아니라 **필기**다. 찍은 점이나 그은 획이 그대로 남고, 그때부터 아이콘은 필기 중처럼 숨는다.
- 누르고 있는 동안에는 아이콘을 옮기지 않는다.

### 10.4 지우개 상태의 아이콘

지우개 도구일 때(뒤집은 지우개든 도구 모음에서 고른 지우개든) 아이콘은 뒤집힌 연필로 보인다.

- **뒤집은 상태는 펜을 멀리 들어도 아이콘이 남는다.** 다시 지우러 펜을 가져왔을 때 거꾸로 선 연필이 보여야 하기 때문이다. 도구 모음에서 고른 지우개는 일반 규칙대로 근접이 끝나면 숨는다.
- **지우는 동안**: 아이콘이 지연 없이 펜 끝에 붙어 다닌다. 아이콘 중심 = (펜 x + 8, 펜 y − 8)이다. 뒤집힌 연필의 지우개 끝이 지우개 원에 오도록 맞춘 값이다. 이 동안에는 미끄러지는 애니메이션이 없고, 아이콘이 입력을 가로채지 않는다.
- **지우기를 마치고 떼면**: 아이콘을 숨기지 않고 뗀 자리의 기본 자리(10.2)로 옮긴다. 떼자마자 아이콘을 눌러 펜으로 돌아가는 일이 잦기 때문이다.

### 10.5 지우개 아이콘 누르기 (지우개 → 펜)

- 지우개 상태의 아이콘을 펜으로 누르면 바로 지우지 않고 기다린다.
- 누른 채 **8보다 멀리** 끌면 지우기로 본다. **누른 자리부터** 지우기 시작하고, 이후 움직임대로 지운다. 도구는 지우개로 남는다.
- 8 이내에서 떼면 (시간 제한 없음) **펜으로 돌아간다**.
  - 뒤집은 지우개였으면 지우개 두께 설정을 뒤집기 전 값으로 되돌린다.
  - 도구 모음에서 고른 지우개였으면 지우개 두께는 그대로 두고 도구만 펜으로 바꾼다.
  - 아이콘이 정방향으로 회전한다. 회전이 끝난 뒤에 펜이 이미 멀어져 있으면 그때 숨긴다. 탭하고 바로 펜을 들어도 회전하는 모습이 보이게 하기 위해서다.

### 10.6 도구 모음과의 관계

- 뒤집힌 상태에서 도구 모음의 펜 버튼을 누르면 펜으로 돌아간다. 지우개 두께도 되돌린다.
- 뒤집힌 상태에서 지우개 버튼을 누르면 뒤집힌 상태를 풀고 지우개 두께를 되돌린 뒤 지우개를 고른다. 그때부터는 도구 모음에서 고른 지우개와 같다.
- 뒤집힌 상태에서 직선 버튼을 누르면 먼저 펜으로 돌린 뒤 직선 도구로 바꾼다.

## 11. 설정 패널

### 11.1 열고 닫기

- 도구 모음의 ⚙︎ 버튼으로 연다. 열린 상태에서 다시 누르면 닫는다.
- 닫는 방법:
  - 패널 오른쪽 위의 `×` (**U+00D7** MULTIPLICATION SIGN, 크기 22, 28×28 버튼).
  - ⚙︎ 버튼을 다시 누름.
  - 하드웨어 키보드의 Esc (Android: 뒤로 가기도 같은 동작으로 하면 자연스럽다).
  - 패널과 ⚙︎ 버튼 **바깥** 아무 곳이나 누름.
- 바깥을 눌러 닫을 때:
  - 그 누름이 **캔버스 위**였으면 닫기만 하고 그 입력은 버린다. 쓰거나 지우지 않는다.
  - **도구 모음의 다른 버튼**이었으면 패널을 닫고 그 버튼도 동작한다.

### 11.2 모양

- 무대 가운데에 뜬다. 폭은 320 (무대 폭 − 32가 더 작으면 그 값, 화면 폭 560 이하에서는 화면 폭 − 24).
- 안쪽 여백 18, 모서리 반지름 16, 배경 흰색 96% 불투명, 뒤 흐림 12, 테두리 `#dde3ea` 1, 그림자 아래로 16 흐림 44 `rgba(24, 34, 49, 0.2)`.
- 제목 "도구 설정"(16), 그 아래 설명 "선의 느낌과 도구 크기를 조절하세요."(12, `#68758a`).
- 각 줄은 왼쪽에 이름(폭 88, 13, `#55637a`), 오른쪽에 조작 요소가 있다. 줄 위쪽에 `#edf1f5` 구분선이 있고, 위아래 여백은 12다.
- 선택 버튼 묶음은 회색 바탕 `#edf1f5`(모서리 8, 안쪽 여백 3, 간격 4) 위에 버튼을 나란히 놓는다. 선택된 버튼은 배경 `#38d579`, 흰 글씨다.

### 11.4 설정 저장

- 위 표의 11개 설정은 바꿀 때마다 저장하고, 앱을 다시 켜면 불러온다.
- **저장하지 않는 것**: 그린 획, 지금 도구, 도구 모음 위치, 패널이 열려 있었는지, 뒤집힌 상태.
- 불러올 때 값을 검사한다.
  - 저장된 색이 지금 견본 4개에 없으면 첫 견본(파랑)으로 시작한다.
  - 도형 대기 시간은 0.5~1.5초 범위로 자른다.
  - 숫자가 아닌 값이나 알 수 없는 값은 버리고 기본값을 쓴다.
- 저장이 실패해도 앱은 그 세션 동안 정상 동작해야 한다.

## 13. 범위 밖

아래는 웹 플레이그라운드에 있지만 개발과 진단용이라서 Android 기능 명세에 넣지 않았다.

- "입력 진단" 패널 (이벤트 로그, 지금 도구 표시, 로그 지우기 버튼).
- "획 JSON 보기" 버튼. 획 데이터를 x·y·t는 정수로, 필압은 소수 셋째 자리로 반올림해 보여 준다.
- 분석 문서 링크들, "펜·지우개 단계별 보기" 페이지(`algorithm.html`).
- 마우스로 지우개를 쓸 때 십자 커서로 바꾸는 것.
- 제목 옆 "저지연 캔버스" 토글(`?desync=on`) 같은 성능 비교용 옵션.
- 층 나누기, 긴 획 앞부분 옮기기, 프레임마다 한 번 그리기 같은 성능 구현.
- 라이브러리의 `setViewOffset`(스크롤에 맞춰 획을 옮겨 그리는 기능). 플레이그라운드에서 쓰지 않는다.
